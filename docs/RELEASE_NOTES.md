npetrov VoiceLab 0.3.0 — нативная замена голоса из личного установщика Dubbing AI.

- Оригинальный SDK Dubbing AI 1.8.2 подключён через восстановленный интерфейс. Это совместимая личная сборка с предоставленным движком, не независимая реализация нейросети.
- 1241 небольшой профиль и три общие модели вместо больших отдельных RVC-моделей. Нативная обработка выполняется на CPU. Для неё не нужно выбирать DirectML или загружать RMVPE.
- Голос можно переключать при включённом микрофоне. Каталог разбит на страницы по 40 карточек, поиск работает по всей библиотеке.
- Названия персонажей не восстановлены. Изначально показаны номера; выбранный профиль можно переименовать, названия сохраняются после обновления.
- Сохранены выбор устройств, виртуальный микрофон VB-CABLE, галочка «Слышать себя», запись WAV, обработка файлов, эффекты и поддержка прежних RVC-моделей. Старые RVC-модели не входят повторно в этот установщик.

Один файл VoiceLab-Setup.exe устанавливается поверх предыдущей версии. Выберите AI-режим и нативный профиль, начните с буфера 160 мс. В принимающей программе выберите микрофон CABLE Output. Оригинальный драйвер Dubbing AI не устанавливается.

В Windows CI проверяются выбор всех профилей, повторная инициализация SDK, разные размеры блоков, обработка реальной речи без доступа к сети и работа установленного EXE. Измерения приложены в native-benchmark.json, пример результата — native-reference.wav. Это тесты CPU сервера; отсутствие прерываний и совместимость инструкций на i7-2600 ещё требуют проверки на вашем ПК. Русские голоса конкретных персонажей по номерам пока не определены.
