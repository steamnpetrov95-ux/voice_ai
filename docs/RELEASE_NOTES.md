npetrov VoiceLab 0.3.1 — меньше буферизации звука.

- В нативном AI появились блоки 80 и 40 мс. Для начала рекомендуется 80 мс; при прерываниях выберите 160 мс. Прежнее значение при обновлении сохраняется; при новой установке выбран нативный блок 80 мс. Короткие блоки не предлагаются для RVC.
- Захват, виртуальный выход и наушники используют небольшие порции, выбранные аудиодрайвером. Вход собирается в блок AI; остаток выходного блока сохраняется между вызовами драйвера. Размер блока AI больше не заставляет драйвер ждать такой же большой порции.
- Очередь входа сокращена. На выходе оставлен запас под пакетную обработку SDK, чтобы короткие блоки не терялись во время скачков нагрузки.
- В строке производительности прямо указано «обработка». Это время вычислений, а не измеренная сквозная задержка от микрофона до принимающей программы. Подсказки объясняют увеличение буфера при прерываниях.

Установите VoiceLab-Setup.exe поверх предыдущей версии. Остановите микрофон, выберите «Буфер AI: 80 мс», затем включите снова. Если звук стабилен, попробуйте 40 мс. Для G435 используйте USB-приёмник LIGHTSPEED; выбирайте устройства WASAPI, по возможности с частотой 48 кГц.

Проверяются реальный SDK, Qt, переключение голосов, частоты 48/44,1 кГц, блоки 40/80 мс и передача одинакового сигнала в основной выход и наушники через разные размеры аудиопорций. На Windows также проверяются длительная обработка, установка EXE, обработка голосов установленной программой и удаление. native-latency.json содержит замеры пяти профилей; это CPU сервера, не пользовательский i7-2600.

Сохранены нативный SDK, библиотека профилей, виртуальный микрофон, прослушивание, запись и прежний RVC-режим. Новые названия профилей в эту версию не добавлены.
