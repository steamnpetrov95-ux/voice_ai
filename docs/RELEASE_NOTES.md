npetrov VoiceLab 0.2.2 — лёгкий AI для снижения нагрузки.

- Новый профиль «Лёгкий AI» включён по умолчанию, в том числе при обновлении с 0.2.1. Сохраняется нейросетевая замена тембра, без загрузки большой сети высоты RMVPE. Высота определяется FFT YIN; точность может отличаться от полного профиля.
- История в лёгком режиме уменьшена с 640 до 160 мс: меньше повторной обработки ContentVec на каждом блоке.
- Потоки ONNX не вращаются в ожидании работы; склейка звука обходится без большой временной матрицы.
- В строке производительности видны профиль, ускоритель и время обработки. Наведение показывает время этапов. Выбор профиля сохраняется и применяется к микрофону и файлам.
- Все шесть голосов проверяются из установленного EXE в обоих профилях. В релизе приложен замер `neural-benchmark.json` на CPU Windows CI. Он не заменяет проверку на i7-2600 и GTX 1050 Ti; отсутствие прерываний на этом ПК пока не подтверждено.

Обновление устанавливается поверх предыдущей версии. Для старта выберите «Лёгкий AI», ускорение «Видеокарта (DirectML)» и буфер 320 мс; при прерываниях попробуйте 480/640 мс. Меньшая нагрузка достигается с возможной потерей точности высоты, а больший буфер увеличивает задержку.

Шесть прежних моделей русской озвучки и подписи персонажей сохранены. Голоса работают без интернета. Сохраняются выбор микрофона, виртуального выхода и наушников, галочка «Слышать себя», запись WAV и отдельный режим эффектов.

Установите `VoiceLab-Setup.exe`, оставив пункт шести нейросетевых голосов. В Windows принимающий микрофон — `CABLE Output (VB-Audio Virtual Cable)`.
